# Результати перевірок каталогу фільмів 28 жовтня 2026 року

## Навантажувальний тест

Тестовий API запущено окремо від робочого каталогу на порту 8001. База містила **20 000 фільмів** і **20 окремих користувачів** із позитивними оцінками. Кожен віртуальний користувач почергово виконував пошук `q=Performance` та запит персональних Top-10 рекомендацій. Процес сервера обмежено двома логічними процесорами. Клієнт працював 1801,75 с і записав [повні числові результати](loadtest-30min.json) та [журнал прогресу](loadtest-30min.log).

| Показник | Результат | Ціль зі звіту |
|---|---:|---:|
| Усього запитів | 13 093 | — |
| Успішних запитів пошуку | 6 531 | щонайменше 1 000 |
| Успішних запитів рекомендацій | 6 543 | щонайменше 1 000 |
| P95 пошуку | 2 599,85 мс | ≤ 800 мс |
| P95 рекомендацій | 4 058,38 мс | ≤ 1 200 мс |
| HTTP 5xx | 0 | < 1% запитів |
| Таймаути з’єднання | 19 із 13 093 (0,145%) | окремо від HTTP 5xx |
| Найдовший розрив прогресу | 359,88 с | безперервний 30-хвилинний прогін |

**Висновок:** необхідну кількість запитів зібрано, але P95 обох операцій перевищує цілі. Через розрив у 359,88 с цей запуск не підтверджує вимогу до безперервної роботи протягом 30 хвилин. Нуль HTTP 5xx сам по собі не означає виконання NFR4.3, оскільки були таймаути і пауза. [Попередній запуск](loadtest-interrupted.json) також мав тривалий розрив; його не використано для висновку.

Це вимірювання на Windows із SQLite. Цільове середовище у вихідному звіті — PostgreSQL 16 на сервері 2 vCPU / 4 GB RAM. Обмеження двома логічними процесорами наближає CPU-умови, але не відтворює повністю віртуальну машину, PostgreSQL чи ліміт RAM. Для остаточного приймання NFR4.1 і NFR4.3 потрібен повторний безперервний тест у цільовому середовищі.

## Перевірка чотирьох сценаріїв у браузері

П’ять **автоматизованих браузерних сесій** створили окремі акаунти й послідовно знайшли Demo Orbit, додали його до Watchlist, поставили оцінку 5 та відкрили персональні рекомендації. Усі п’ять завершили чотири дії. Після сценарію перевірено, що БД містила п’ять актуальних оцінок, п’ять записів Watchlist і десять подій UserInteraction. Тестові акаунти після перевірки видалено. Докази: [JSON результат](five-ui-sessions.json) і [знімок сторінки рекомендацій](ui-check-recommendations.png).

Під час першого браузерного прогону виявлено помилку навігації: пізня відповідь після оцінювання могла повторно відкрити сторінку фільму поверх рекомендацій. Її виправлено у `frontend/src/main.tsx`, після чого всі п’ять повторних сесій пройшли.

**NFR4.4 не підтверджено.** Користувач повідомив, що п’ятьох реальних учасників зараз немає. Часи автоматизованих сесій не характеризують людську зручність користування і не порівнюються з порогом 60 секунд. Для проведення дослідження підготовлено [протокол із порожньою таблицею результатів](usability_protocol.md).

`pytest`: **10 тестів пройшли**. Production build React/TypeScript завершився успішно. Покриття гілок: `interactions.py` — **8/8 (100%)**, `recommendation.py` — **27/32 (84,4%)**. Вимога NFR4.5 щодо покриття гілок обох модулів ≥80% виконана.
